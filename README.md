# Benkei2

Benkeiは、MacOSで薙刀式(v18)かな入力を行うためのソフトです。薙刀使いである弁慶から名前を採用しました。
完全に書き直したので、Benkei2と呼称することにします。

## 先代Benkeiからの主な変更点

1. QMK薙刀式のかな変換と同じように、かな変換候補が絞り込める時は積極的に確定していきます。
2. 先代Benkeiが、親指シフトのLacaille(kkadowaki氏作)をベースにしていたのに対し、Benkei2はSwiftでスクラッチから書き直したアプリケーションです。
3. カナ変換設定をYAMLファイル(`Naginata.yaml`)から読み込むようにしました。設定ファイルはアプリバンドルに同梱されており、変更する場合はソースを修正してビルドし直してください。

## 初回実行の際

Benkei2はAppleに認証されたソフトウェアではないので、初回起動時に次の手続きが必要です。

1. ダウンロードしたzipを解凍し、隔離属性を外す。

```
xattr -d com.apple.quarantine Benkei2.app
```

2. Benkei2を起動する。
3. 「Benkei2は開いていません」と表示されるので、完了を押してください。
4. システム設定のプライバシーとセキュリティで「Benkei2がブロックされました」とあるので、「このまま開く」を押してください。
5. さらにそのまま開くを押して、ログインパスワードを入力してください。
6. アクセシビリティアクセスのダイアログが開くので、「システム設定を開く」を押す。
7. システム設定のプライバシーとセキュリティ、アクセシビリティが開くので、Benkei2のトグルスイッチをオンにする。
8. メニューバーの「薙」アイコンを開いて、終了する。
9. 再度、Benkei2を起動する。

## 薙刀式の仕様

- [x] ctrl+shift+0で薙刀式をオフにして通常の入力へ戻る（サスペンド）、
- [x] ctrl+shift+1で再開。

- [x] IMEオフ（半角、英数直接入力モード）は、FG同時押し。
- [x] IMEオン（全角、カナ漢字変換モード）は、HJ同時押し。

- [x] ctrl, cmd, optを押している時はqwerty配列に戻る。
- [ ] SandS（シフトキーとスペースキーを兼ねる）を使用。
- [ ] MV同時押しにエンター。

- [x] 単打面、シフト面
- [x] その他同時押し面
- [x] 編集モード
- [x] 固有名詞モード
